# Netflix Data Analysis using Python

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. The objective is to clean the dataset, analyze trends, visualize important patterns, and derive meaningful business insights from the data.

The project demonstrates practical data analysis skills using real-world data and covers the complete EDA workflow, from data cleaning to visualization and business recommendations.

## Objectives

- Perform data cleaning and preprocessing.
- Explore the Netflix dataset using Exploratory Data Analysis (EDA).
- Visualize trends using charts and graphs.
- Identify patterns in content type, release years, countries, genres, and ratings.
- Generate business insights and recommendations based on the analysis.

## Dataset

- **Dataset Name:** Netflix Movies and TV Shows
- **Source:** Kaggle
- **Number of Records:** 8,807
- **Number of Columns:** 12

### Dataset Features

- show_id
- type
- title
- director
- cast
- country
- date_added
- release_year
- rating
- duration
- listed_in
- description

## Key Insights

- Movies make up a larger portion of Netflix's content library than TV Shows.
- The number of titles added to Netflix increased significantly after 2015.
- The United States contributes the highest number of titles in the dataset.
- Drama, Comedy, and International Movies are among the most common genres.
- Most content on Netflix was released between 2017 and 2020.
